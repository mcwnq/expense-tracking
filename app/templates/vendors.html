Vendors and rules

A rule is text to look for at the start of a word in the card description (not case-sensitive), so "FL" matches "PAYPAL *FLOWTRADE" but not "NETFLIX". When several rules match, the longest one wins, so "APEX RESET" can go to a different vendor than "APEX". Type is detected automatically (charged in 3+ months, or 2 months in a row, means recurring) unless you set it.

Each vendor's business says which T2125 its charges go on: Futures, Options & Stocks, or Shared between the two by the split below. New vendors start as Futures for prop firm evaluations and Shared otherwise.

Charges from one vendor can belong on different T2125 lines, such as a course and a software subscription. Use Duplicate to make a copy with the same category and no rules, rename it and set its category, then move those lines to it on the Transactions page. New charges keep going to the vendor whose rule matches.
